# Playground surface

Mode: Operate, with a gallery of educational motion examples.

## Direction contract

THESIS: A rack of motion samples that can be taken apart. The examples occupy the first viewport; there is no marketing hero before the work.

OWN-WORLD: Cool off-white canvas, dark graphite type, a single cobalt control accent, and distinct muted lavender, apricot, blue, and green demo fields. Workhorse UI typography, generous sample stages, compact tools, and no ornamental gradients or glow.

STORY: Browse, try, inspect, take. Visitors can start with a project collection or everyday/expressive purpose, narrow by technology and complexity, recognize an effect, test it at several speeds, understand where it belongs, and copy a complete example or an agent brief. The selected project palette travels from the preview into that portable source.

FIRST VIEWPORT: Slim left category rail, compact utility header, a clear gallery title at 38px, and one sentence of context. Project collections and compact discovery controls lead into a three-column wall of working samples. Each sample has a 230px stage and a name beneath it. A shared native color disclosure previews Original, Radix, Geist-inspired, or custom palettes in Light, Dark, or Match site; it starts open on desktop and closed at widths of 780px or less so the phone view reaches its first study sooner. The detail page pairs a large interactive stage with readable source, usage notes, and color integration. Mobile turns the rail and project collections into horizontal strips and shows one generous sample per row.

FORM: Material sample rack, grounded candidate 7, seed 9ce89a2d. Other grounded candidates: component catalog, compositor, curve instrument, studio notebook, timeline editor, reference index. The extra design-reference service was unavailable; no catalog challengers were returned. The user delegated the choice and explicitly forbade questions. The build proceeds directly from this contract.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
