# Playground surface

Mode: Operate, with a gallery of educational motion examples.

## Direction contract

THESIS: A rack of motion samples that can be taken apart. The examples occupy the first viewport; there is no marketing hero before the work.

OWN-WORLD: Cool off-white canvas, dark graphite type, a single cobalt control accent, and distinct muted lavender, apricot, blue, and green demo fields. Workhorse UI typography, generous sample stages, compact tools, and no ornamental gradients or glow.

STORY: Browse, try, inspect, take. Visitors can recognize an effect, test it at several speeds, understand where it belongs, and copy a complete example or an agent brief.

FIRST VIEWPORT: Slim left category rail, compact utility header, a clear title at 40px, one sentence of context, then a three-column wall of working samples. Each sample has a 230px stage and a name beneath it. The detail page pairs a large interactive stage with readable source and usage notes. Mobile turns the rail into a horizontal category strip and shows one generous sample per row.

FORM: Material sample rack, grounded candidate 7, seed 9ce89a2d. Other grounded candidates: component catalog, compositor, curve instrument, studio notebook, timeline editor, reference index. The extra design-reference service was unavailable; no catalog challengers were returned. The user delegated the choice and explicitly forbade questions. The build proceeds directly from this contract.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
