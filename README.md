# Animation Playground

A reusable web animation library is being built here, informed by [Emil Kowalski's animation skills](https://github.com/emilkowalski/skills).

**Status: construction in progress.** Follow [the build issue](https://github.com/spencer-life/animation-playground/issues/1) for scope and delivery status.

The planned playground includes live demonstrations, explanations, copyable self-contained code, and stable references for future design projects. It will use static HTML, CSS, and JavaScript.
